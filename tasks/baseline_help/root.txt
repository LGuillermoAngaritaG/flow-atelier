 flow-atelier: run reproducible async DAG workflows (conduits).

╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ init       Scaffold a local .atelier/ directory with a hello-world conduit.  │
│ run        Start a new flow for the named conduit. Use --input key=value to  │
│            pass inputs.                                                      │
│ status     Show progress for a flow.                                         │
│ logs       Show recorded stdout/stderr/output for each task in a flow.       │
│ serve      Run the FastAPI HTTP + WebSocket server with the embedded         │
│            scheduler.                                                        │
│ list       List conduits or flows.                                           │
│ schedule   Manage scheduled conduit runs (.atelier/schedules.json).          │
│ scheduler  Run and inspect the scheduler daemon.                             │
