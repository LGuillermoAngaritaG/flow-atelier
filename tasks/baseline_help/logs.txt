                                                                                
 Usage: atelier logs [OPTIONS] FLOW_ID                                          
                                                                                
 Show recorded stdout/stderr/output for each task in a flow.                    
                                                                                
╭─ Arguments ──────────────────────────────────────────────────────────────────╮
│ *    flow_id      TEXT  Flow id (or unique prefix) to inspect. [required]    │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --task    -t      TEXT     Show only entries for this task.                  │
│ --show    -s      TEXT     Which channel to print: output | stdout | stderr  │
│                            | all.                                            │
│                            [default: output]                                 │
│ --last    -n      INTEGER  Show only the last N entries.                     │
│ --follow  -f               Tail mode: print existing entries, then poll for  │
│                            new ones until the flow finishes.                 │
│ --json                     Emit machine-readable JSON instead of panels.     │
│ --help                     Show this message and exit.                       │
╰──────────────────────────────────────────────────────────────────────────────╯
